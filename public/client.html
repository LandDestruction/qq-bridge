会话

可操作

来自 GET /api/sessions 与 /api/socialV2/states；点一行看最近消息，可对选中的会话执行重置。重置会清掉在途回合与会话表，下次群消息到达时重建。

人设

可操作

来自 GET /api/roles 与 /api/roles/content；可切换当前角色、改正文、新建角色卡、改名、删除。改正文会整篇覆盖所选角色的内容（旧内容不可找回），删除角色文件同样不可撤销，删掉当前角色会让桥接回到默认人格。

记忆

可操作

总览来自 GET /api/memory/overview（跨会话群友印象、共享事件、每会话条数），单会话详情来自 GET /api/socialV2/memory?key=。话题 / 未说出口的话 / 群友印象可单条删除或整类清空，不可撤销，但只影响当前会话。

黑话库

可操作

数据流：群聊自动提取 + AI 用 qq_slang_submit 提交 → 人工确认（先填含义）→ 写进黑话提示词、注入 AI 上下文。来源 GET /api/slang（写接口 PATCH / POST / DELETE /api/slang…）；「升为可用」只有人能点——词条先经确认，再决定是「可用」还是「仅听懂」。删除 / 清空 / 批量删除都不可撤销。

表情

可操作

来自 GET /api/stickers；可写备注、切换「可用 / 只解读」策略、删除、同步收藏、检查修复。删除收藏表情不可撤销（可再从 QQ 客户端收藏）。

素材库

可操作

按分类、店铺、来源、标签挑素材；点封面看详情，卡片上可直接找号、改名、补封面。

转存与存储

可操作

转存条件、在电脑上的文件夹、清理与磁盘余量都在这里；素材的浏览 / 找号 / 补封面 / 合并 / 下载都搬到「素材库」页。

名单

可操作

来自 GET /api/lists；白名单 / 拒绝 / 观察 / 归档 / AI 黑名单都在这页改，写回 config.json 前会二次确认并备份。拒绝名单优先于白名单。

模型与高峰

可操作

空闲/高峰模型、降级链、禁用清单与暂停聊天；写操作先二次确认，保存后下一轮生效。

用量与花费

只读 + 重置

总账、花费走势、各会话花费与逐轮明细来自 GET /api/tokens/*；「重置账本」只清零统计，不动任何消息数据。

系统架构

一张图看懂：消息从哪个群进来、经过桥接的哪几层、最后被哪个模型回出去，以及省 token 的三个闸。数据来自 GET /api/ops/services、GET /api/status、GET /api/tokens/summary 与「模型与高峰」页那份 GET /api/model-routing，不新增接口。

日志

可清空

按聊天流看：群友说话靠左、机器人说话靠右，机器人的系统动作（等消息 / 调工具 / 改配置）也靠左，用灰色虚线气泡标出来（点「原始参数」看当时的入参）。打开就在最新一条。服务日志在「运维」。

运维

可操作

来自 GET /api/ops/services、GET /api/ops/status 与 GET /api/self-check/last；启停走 POST /api/ops/action（二次确认后才发），自检走 POST /api/self-check（只读体检，不改配置）。

设置

可操作

外观在这里调；写配置会直接落到线上 config.json，保存前会二次确认，端口 / 白名单 / 连接类键要重启桥接才生效。

工具开关

可操作

来自 GET / POST /api/tools/gate：逐个开关机器人能调用的工具。这是隐藏页——设置页连点版本号 5 次，或用带 ?dev=1 的地址打开本页。
