# 群管理指令表

> 指令在**桥接层**处理，不进入 agent 回合：响应快、不烧 token、静默期间也能用。
> 权限分三级：`群成员` < `群管理`（群主/管理员/机器人主人） < `主人`（仅 ownerQQ）。

## 一、控制类（群管理）

| 指令 | 状态 | 说明 | 示例 |
|---|---|---|---|
| `/stop` | ✅ 已实现 | 本群静默，直到 `/resume`（实际 7 天封顶） | `/stop` |
| `/stop 10` | ✅ 已实现 | 静默 10 分钟，到期自动恢复 | `/stop 10`、`/stop 2h`、`/stop 30s` |
| `/resume` | ✅ 已实现 | 解除静默 | `/resume` |
| `/mute @某人 30` | ⏳ 待实现 | 只对某个人静默 30 分钟，别人照常 | `/mute @阿虚 30` |

**静默期间**：群里普通消息直接忽略（连唤醒都不触发）；指令仍可用，否则喊停后就叫不回来。

## 五、权限与实现细节

**权限判定**

```
ownerQQ            → owner（全部指令）
群主 / 群管理员      → admin（控制类 + 总结类 + 检索类）
普通群成员           → member（检索类 + /help）
```

群主/管理员通过 OneBot `get_group_member_info` 的 `role` 字段判定，**每个 (群, 人) 缓存 10 分钟**，避免每条指令都打接口。

**无权限时**：回一句「这个指令需要群管理权限（群主/管理员/机器人主人）。」，不执行、不进入 agent。

**时长写法**：`10`（默认分钟）、`10m`、`30s`、`2h`、`1d`。

**状态持久化**：静默写到 `state/group-mutes.json`，重启后仍生效。
