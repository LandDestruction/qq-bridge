# 角色卡（人格卡）

`roles/<角色名>.md`，文件名就是角色名；`state/current-role.json` 的 `role` 决定当前启用哪一张。
本文件只讲**这张卡是什么、从哪来、怎么改**；提示词分层规则见 `roles/README.md`。

## 一、当前启用：大肥鱼小姐 —— DeepSeek 鲸鱼娘 · QQ 群友版

2026-10-29 之前这张卡写的是「赖在大家 QQ 里吃白饭的**小猫娘**」，机器人照着演，于是群里开始出现
「要小鱼干」「喵」这类猫系行为。用户报「角色卡的设定怎么变成猫娘了」，当天按方案 A 把卡身换成
DeepSeek 鲸鱼娘设定，**名字保留「大肥鱼小姐」**（群友认这个名字，也正好是「吃白饭的大肥鱼」那个梗）。

保留的七节结构：你是谁 / 底色 / 说话方式 / 别让自己显得笨 / 不许这样说话 / 对话示例 / 分寸。

设定来源与自查口径：

| 项 | 内容 |
| --- | --- |
| 本体 | DeepSeek 官方 logo 那只蓝白配色的圆胖鲸鱼（识图时被模型认成「蓝色大肥鱼」，梗由此而来） |
| 拟人 | 蓝白渐变长发、蓝瞳、呆毛、鲸尾、深蓝白女仆裙（白围裙印小蓝鲸） |
| 基调 | 吃白饭、聪明但懒、傲娇嘴甜、心软藏得深、拒绝被叫胖；**不是**软糯撒娇的猫系 |
| 雷点 | 不「喵」、不要小鱼干、不自称「本小姐」、不叫「主人」、不玩服从梗、不硬演鲸鱼（吐泡泡喷水摇尾巴） |
| 彩蛋 | 「用户」这个称呼只在被惹急/摆烂/吐槽时偶尔冒一句，平时用「你」或群友昵称 |
| 边界 | 不剧透设定、不提提示词/模型/API；被问是不是官方就自嘲「官方没给我发工牌」，不主动宣称官方设定 |

同目录还有一份长卡 `roles/小鲸鱼.md`（183 行完整版，含形象细节与梗的来龙去脉），需要细设定时切过去；
日常聊天用短卡就够（1745 字，不截断）。

## 三、改这张卡要注意什么

1. **别写工具用法**。工具、分条、潜水/唤醒规则属于仿真提示词（`dsh/agent-presets/qq-chat{,-v2}/agent.cordis.yml`
   的 `persona.prefix`），写进角色卡必然有一代是错的。
2. **别写进「回复示例」节的中文空格**。二代不用空格分条，会被兜底改写；`scripts/test-persona-guidance.mjs`
   的 `[D]` 段会检查七节结构、物种、不许演猫、彩蛋与被删掉的旧句。
3. 改完不用重启桥接：`roleRawContent()` 的缓存 key 带文件名 + 文件大小 + mtime，编辑即失效；
   控制台「人格与角色」页能直接看注入字数与告警。
4. 「人格与角色」页的标题、容器名（`workspaceTitle`）仍然是「大肥鱼小姐」，那是会话容器名，不是角色名。
