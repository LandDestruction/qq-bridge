# 给朋友的安装与上手说明（QQ DeepSeek Bot 0.2.2）

这份文档是写给「拿到安装包、想自己跑起来」的人看的。按顺序做，大约 20 分钟能跑通第一句话。

> 先说实话：这个安装包**只包含本项目自己的东西**（桥接、控制台、桌面壳、人设/预设、素材库）。它**不含**两样第三方软件：
> 1. 模型运行时（DeepSeek Harness，简称 DSH）**或**一个 OpenAI 兼容的 API Key；
> 2. QQ 网关（SnowLuma）与一个能登录的 QQ 小号。
> 这两样在下面第 4、5 步配。缺了它们，程序能打开，但机器人不会说话。

---

## 1. 你需要准备

| 东西 | 说明 |
|---|---|
| Windows 10/11 64 位 | 安装包是 `QQDeepSeekBot-Setup-0.2.2.exe`（约 56 MB），自带你需要的 Node 运行时，不用另外装 Node |
| 模型后端（二选一） | ① 本机装好 DSH（自带登录）；② 任意 OpenAI 兼容 API（如 DeepSeek 官方 `https://api.deepseek.com/v1` + `sk-…`） |
| QQ 网关 | SnowLuma（项目自备可执行文件），用一个**小号**登录，建议不要用主号 |
| 一个空目录 | 素材库/状态文件会写在这里，约几十 MB 起 |

> 建议用 QQ 小号：机器人行为再稳，也不值得拿主号冒险。

---

## 2. 安装

1. 双击 `QQDeepSeekBot-Setup-0.2.2.exe`，一路下一步（默认装在 `%LOCALAPPDATA%\QQDeepSeekBot`）。
2. 装完会在开始菜单出现 **QQ Deep Bot**，桌面一般也会有一个快捷方式。
3. 安装器会在后台把桥接起来一次；如果没起来，见第 7 节「常见问题 Q1」。

---

## 3. 第一次打开

1. 从开始菜单/桌面打开 **QQ Deep Bot**，会弹出一个窗口（本质是 WebView2 壳，加载本机控制台）。
2. 浏览器也可以直接开：<http://127.0.0.1:3100/client>。
3. 第一次打开如果提示输入令牌：令牌在安装目录的 `state/console-token` 文件里（纯文本，复制粘贴）。

---

## 4. 配置模型后端（必须）

打开控制台 → **设置 → 模型与思考 → 模型后端**，三种选一个：

### 路线 A：用本机 DSH（推荐给已经装过 DSH 的人）

- 后端选 **DSH**，地址留空（默认 `http://127.0.0.1:1076`）。
- 点「测试连通」：显示「DSH 在线，需要鉴权」也算通（401 是正常的，说明 DSH 活着）。

### 路线 B：用 OpenAI 兼容 API（不需要 DSH）

- 后端选 **OpenAI 兼容**，填：
  - 接口地址：`https://api.deepseek.com/v1`（末尾斜杠会自动去掉）
  - 模型名：`deepseek-chat`（按你的服务商要求填）
  - API Key：`sk-…`（**只写不读**，保存后页面不会再显示，请自己留好）
  - 超时 120 秒；最大工具轮数 8（不懂就别动）
- 点「保存后端配置」，再点「测试连通」，应显示 `✓ 连通`。
- **切换后下一轮才生效**；切回 DSH 不会影响已有配置。

---

## 5. 配置 QQ 网关（必须）

1. 启动 SnowLuma，用你的 **QQ 小号**扫码登录，确认它的 OneBot HTTP 在 `127.0.0.1:3000`、WS 在 `127.0.0.1:3001`（默认）。
2. 打开安装目录的 `config.json`，确认这一段（没有就补上）：

```json
"snowluma": {
  "wsUrl": "ws://127.0.0.1:3001",
  "httpUrl": "http://127.0.0.1:3000",
  "accessToken": "把 SnowLuma 里配的 token 填这里"
}
```

3. 重启桥接（或在控制台「运维」页点重启）。日志里出现 `snowluma.connected` 就说明通了。
4. 让这个 QQ 小号加进你要它待的群；它默认只响应**被 @、被点名、被提问**（可在「设置 → 唤醒」里调）。

---

## 6. 跑通第一句话

1. 控制台「仪表盘」右上角应显示「运行正常 / QQ 你的小号 / 版本 0.2.2」。
2. 用另一个号在那个群里 @ 它，说「你好」。
3. 看控制台「日志」或「会话」页，应能看到入站消息、一次模型调用、一条发出。

---

## 7. 常见问题

**Q1 打不开窗口 / 页面空白？**
浏览器开 <http://127.0.0.1:3100/client>。仍空白说明桥接没起：安装目录里双击 `node.exe` 不信就手动开终端跑 `node src\bridge.js`，看报错。

**Q2 控制台 401？**
需要令牌：`state\console-token` 文件内容，粘到页面的令牌框（或 URL 加 `?token=…`）。

**Q3 机器人不回话？**
按顺序查：① SnowLuma 是否在线、QQ 是否登录；② 日志有没有 `snowluma.connected`；③ 有没有被 @；④ 模型后端「测试连通」是否通过；⑤ 是不是被「唤醒」规则拦了（设置 → 唤醒，或 AI 黑名单）。

**Q4 私聊发表情/图片失败？**
QQ 平台限制：对方不是好友时，临时会话**只能发文字**，表情和图片会被服务端拒绝（OIDB 170019003）。让对方加好友，或改到群里发。

**Q5 端口被占？**
控制台默认 3100，被占用会启动失败；改 `config.json` 的 `console.port`。

**Q6 怎么关掉开机自启？**
如果安装时开启了自启：运行安装目录里的 `scripts\autostart.ps1 -Action uninstall`（或计划任务里删掉 `QQDeepSeekBot Bridge`）。

**Q7 卸载？**
设置 → 应用 → 「QQ Deep Seek Bot」→ 卸载。想连数据一起清掉，再删 `%LOCALAPPDATA%\QQDeepSeekBot`。
